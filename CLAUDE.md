# Frespresso Cafe & Resto website

Build the website from the design handoff in `design/`. Read `design/README.md` first.

## Sources of truth
- **Visual spec:** `design/boards/*.dc.html`. Each page has a desktop file plus `-Tablet` and `-Mobile` wrappers around the same page. Shared pieces are in `Header.dc.html`, `Footer.dc.html` and `Logo.dc.html`.
- **Styles:** `design/assets/frespresso.css`, which holds the tokens and the `.fx-*` component classes. Reuse the class names and tokens; don't invent new colours or sizes.
- **Copy and data:** `design/content/site-content.json`, covering the business facts, menu, ratings and navigation.
- **Logos and favicon:** `design/assets/logo/`.
- **Original briefs:** `DESIGN_PROMPT.md` and `WEBSITE_PROMPT.md` (if present).

## Implementation
- The site is static HTML generated by `node tools/build.js` from the boards plus `data/site.json`, `data/testimonials.json` and `data/gallery.json`. The root `.html` files and `css/frespresso.css` are build output; edit the sources and rebuild. See `README.md`.
- Preview with `node tools/serve.js` (http://localhost:5173).
- Additions beyond the original design: a testimonials carousel (Home, Reviews), a gallery preview on Home, and video tiles plus a Videos filter in the Gallery.

## Rules
- Seven routes: `/`, `/about`, `/menu`, `/experience`, `/gallery`, `/reviews`, `/contact`.
- Breakpoints:
  - Mobile: 640 px and below, single column, hamburger drawer, floating call button.
  - Tablet: 641–1100 px, two columns.
  - Desktop: 1101 px and up, content width 1200 px.
- Convert the `@container page` rules in the CSS to `@media` queries.
- Touch targets must be at least 44 px. Body text contrast must be at least 4.5:1, and the token colours already pass.
- Implement the `data-motion` hooks as described in `design/boards/Motion.dc.html`, and respect `prefers-reduced-motion`.
- Do not invent reviewer names, awards, opening hours or menu items.
- Keep images as labelled placeholders until the cafe supplies its own photos. Never take images from Google, Swiggy or social media.
- Phone links use `tel:+917887323311`. Instagram: https://instagram.com/frespressosolapur.
